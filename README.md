# RAG 06 — GraphRAG & Knowledge Graphs

Covers graph-augmented retrieval: why multi-hop questions benefit from graph structure, Microsoft GraphRAG's entity extraction and community summaries, knowledge graph construction and entity resolution, property graphs (Neo4j, Memgraph, KuzuDB, NetworkX) versus RDF triplestores, hybrid graph + vector retrieval, Cypher queries in agent loops, and practical guidance on when graphs help versus hurt.
